# サンプルテンプレート集

このファイルには、承認リクエストで使用できるMarkdownテンプレートのサンプルが含まれています。

## 休暇申請テンプレート

```markdown
# 休暇申請

## 申請者情報
- 氏名: {申請者名}
- 部署: {部署名}
- 連絡先: {電話番号/メール}

## 休暇情報
- 休暇種類: {有給休暇/特別休暇/代休/その他}
- 休暇期間: {開始日} ～ {終了日}
- 日数: {X}日間
- 理由: {休暇の理由}

## 業務引継ぎ
- 引継先担当者: {担当者名}
- 緊急連絡方法: {連絡方法}

## 備考
{その他連絡事項}
```

## 使用方法

1. システムにログイン後、「テンプレート管理」を選択
2. 「テンプレート追加」を選択
3. 上記のテンプレートをコピー＆ペースト
4. テンプレート名と説明を入力
5. 保存

テンプレートは後から編集できます。`{変数名}`の部分は、実際の承認リクエスト作成時に具体的な値に置き換えてください。
